## Környezet és hatókör

Helyi macOS munkatér, Node REPL JavaScript VM; CommonJS, node:assert/strict. Automatizált tesztek a tényleges script.js függvényével, szimulált DOM/sessionStorage és játékállapot. Nincs éles játékadat módosítva. Forrás: script.js, tests/round-summary-gating.test.cjs; webes verzió 1.9.3. Natív build külön: GitHub Actions, Android Gradle és Xcode iOS-szimulátor, forrás 2dded917eb8561da9c27195eb1c7cbda439c2fdc.
