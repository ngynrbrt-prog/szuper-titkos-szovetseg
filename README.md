# A Szuper Titkos szövetség — 0.5 (UI redesign)

Az előző 0.4 prototípus modernizált felülete. Mobilon lebegő, üveghatású alsó navigáció, letisztult kártyák, korszerű tipográfia, nagyobb érintési célok és új térképkeret. A teljes menü továbbra is a fejlécből nyitható (admin, regisztráció, helyszínek).

## GitHub Pages frissítése

A ZIP-ben lévő összes fájlt töltsd fel a repository gyökerébe, a korábbi azonos nevű fájlokat cseréld le. Az új `modern.css` fájlt is feltétlenül töltsd fel! A `config.js` a városok és útvonalak konfigurációja.

## Korlátok

Ez továbbra is **helyi, egyszemélyes prototípus**. Nincs szerveroldali adminhitelesítés, multiplayer, valós Sauron-üldözés. A PIN a böngészőben, nem biztonságosan tárolódik. A térkép internetet igényel. GPS-hez HTTPS szükséges. A 0.5 kiadás a felületet alakítja át, a játékmenetet nem.
