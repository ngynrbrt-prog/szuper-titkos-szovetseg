A Szuper Titkos szövetség v0.6 – Sauron-jelölő javítás.

Mindkét térképes Sauron-jelölő kizárólag ugyanazt a fekete sisak SVG-t használja. A jelölő minden zoomszinten megjelenik, szem és kérdőjel nélkül. Előkészületben a bizonytalan észlelés a világ különböző pontjain jelenhet meg, háromóránként frissül. A prototípus továbbra is helyi, nem multiplayer.

GitHub Pages: az index.html, script.js, config.js, style.css, modern.css fájlokat a repository gyökerébe töltsd fel, a korábbiak helyére.
